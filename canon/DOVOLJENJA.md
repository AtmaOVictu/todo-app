# Public permission register

This file is retained for historical VBL 2.6 records. It does not grant or
modify permissions under the repository's current software licenses. No
permissions are recorded yet. The template below is not itself permission.

For each grant, record the asker, the deed, the material, the place where it
will be used, the decision date, and the exact scope and conditions of the
permission. Do not add an entry until the permission has been granted in
writing.

## Entry format

```text
### Permission — YYYY-MM-DD
- Asker:
- Deed:
- Material:
- Place:
- Scope and conditions:
- Written decision/reference:
```
